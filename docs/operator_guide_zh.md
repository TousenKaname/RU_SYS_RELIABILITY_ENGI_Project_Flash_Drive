# FlashRel Rig 2 操作手册（Run 2：20 个 U 盘，120 小时）

本手册给在测试电脑旁操作的人用。设计细节见 `test_plan_run2.md`。

## 0. 需要准备的东西

| 物品 | 数量 | 说明 |
| --- | --- | --- |
| Windows 10/11 台式机 | 1 | 有 2 个空闲的 USB-A 口（最好在机箱背面）；能用管理员账户 |
| Sabrent HB-BU10 拓展坞 + 12V/5A 电源 | 2 | 两个电源插同一个插线板（有 UPS 更好） |
| ABLAZE 16 GB | 10 | 编号 A16-03 … A16-12 |
| ABLAZE 8 GB | 10 | 编号 A8-06 … A8-15；其中 A8-09、A8-15 是备用盘 |
| SanDisk 8 GB（run 1 用过的） | 2 | S8-01、S8-02（软件会核对它们的 USB 序列号） |
| 标签纸、记号笔 | | 给 U 盘和拓展坞口编号 |
| 温度计/红外测温枪（可选） | 1 | 每天记一次室温和拓展坞温度 |

## 1. 装软件（5 分钟）

1. ZIP 若是下载来的：右键 → 属性 → 勾选“解除锁定” → 确定，然后解压。
2. 把 `FlashRel-Rig` 整个文件夹放到 `C:\FlashRel-Rig`。不要放在 OneDrive/Google Drive/Dropbox 同步文件夹、U 盘或网络盘里。
3. 不需要装 Python：文件夹里 `runtime\` 就是官方 Python（python.org 的 embeddable 版）。

## 2. 接线（10 分钟）

1. 拓展坞接电源，所有口的开关拨到 ON（灯亮），整个测试期间不要再动开关。
2. 拓展坞 A 的线插到电脑背面一个 USB 口，拓展坞 B 插到另一个**相隔较远**的背面口。
   - 不要插前面板、不要用延长线或扩展坞转接、不要把一个拓展坞插进另一个。
   - 原因：每个拓展坞上的 10 个 USB 2.0 盘共用一条约 40 MB/s 的通道；两个坞各占一个电脑口才各有一条通道。
3. 用标签纸给每个拓展坞的口编 1–10（1 号 = 离线缆最近的口），在两个拓展坞上分别写 A 和 B。
4. 给 22 个 U 盘贴编号（见上表），编号写在盘身上。
5. 测试盘只插在拓展坞上，电脑本身的 USB 口不插测试盘（run 1 的教训：电脑自带的某些口会被 Windows 当成“内部口”，写入策略不同）。

## 3. 启动和准备（约 1 小时）

双击 `Start FlashRel.bat` → Windows 询问管理员权限点“是” → 浏览器打开仪表盘（地址类似 `http://127.0.0.1:8585/`）。黑色窗口显示 “FlashRel Rig is running” 后可以关掉。

在 **Setup** 页依次做：

**① Prepare the PC**：每一项是绿色最好。红/黄的项右边有按钮（例如 “Set sleep/hibernate to never”、“Pause updates for 10 days”、“Disable USB selective suspend”、“Turn AutoPlay off”、“Exclude the rig's Python from Defender”），点一下即可，修改会被记录，测试后可在同一页 “Undo host changes” 还原。

- “No restart pending” 若是红色：先重启电脑再开始测试。
- 点了 “Pause updates for 10 days” 后，到 Windows 设置 → Windows 更新 里确认显示“已暂停更新至 …”；没显示就在那里手动点“暂停更新”。
- 如果装了第三方杀毒软件（如 McAfee），尽量把测试盘排除在实时扫描之外，做不到就算了（会在报告里注明）。
- 用操作 PC 的那个账户（管理员）登录并运行；不要用“普通账户 + 输入别人的管理员密码”的方式提权。

**② Connect the two hubs**：页面上画了 A、B 两个坞每个口对应哪个盘（随机但每个坞都是 5×A16 + 4×A8 + 1×S8）。

**③ 备用盘自检**：把 A8-09 插到任意一个拓展坞口 → 在第 ④ 步的列表里点 “Enroll as A8-09”（会格式化）→ 回到第 ③ 步点 “Self-test on A8-09”（约 2 分钟，全部打勾才算通过）。再插 A8-15 登记。之后把两个备用盘拔下来保管好（测试后要用）。

**④ 逐个登记 20 个测试盘**：页面上方的蓝框会提示下一个盘，例如 “A16-10 → hub A, port 1”。
1. 把贴着这个编号的盘插到指定的口；
2. 几秒后列表里出现新盘，核对大小（8 GB 或 16 GB），点 “Enroll as A16-10”，确认对话框里写的就是这个盘再点确定（**会清空这个盘**）；
3. 等出现 ✓（十几秒），盘留在原处不拔，接着插下一个。格式化进行时所有 “Enroll” 按钮都是灰的，一次只能登记一个盘。

如果列表里同时出现好几个新盘，要特别注意选对；大小不对的盘没有登记按钮（例如把 8 GB 的盘当成 16 GB）。S8-01/S8-02 如果插反了软件会根据 USB 序列号拒绝。
文件系统显示 “RAW”（Windows 读不出文件系统）的盘软件不会格式化：如果确定是新的测试盘，先在“此电脑”里右键它 → 格式化（exFAT）→ 再回来登记。

**⑤ Start**：没有红色问题后点 “Start the 120-hour test”。如有黄色警告会再确认一次。20 个盘每隔 15 秒启动一个，大约 5 分钟后全部在跑。

## 4. 测试期间（120 小时）

- 仪表盘可以关掉，测试在后台照跑；想看时再双击 `Start FlashRel.bat` 即可重新打开。
- **不要**：拔插 U 盘、动拓展坞开关、让电脑睡眠/关机/更新重启、对 Windows 弹出的“扫描并修复”“需要格式化”点确定（一律取消）。
- **每天一两次**看一下：
  - 顶部的倒计时、Overview 页两个拓展坞的卡片（绿=写、蓝=读校验、橙=删除、粉=ATTENTION、红=FAILED、灰=CENSORED）；
  - 右下 Events 里的失败记录；
  - Data & control 页记一条温度（室温、拓展坞外壳），有异常情况写一条 note（例如“停电 10 分钟”“有人碰了线”）。
- 坏掉的盘（ATTENTION/FAILED）**留在原位不要动**，测试结束后统一处理。
- 想在测试中看数据：用仪表盘，或先把 CSV **复制**一份再用 Excel 打开。直接用 Excel 打开正在写的 CSV 也不会丢数据（软件会先暂存、之后补写），但尽量别这样做。
- 如果整台电脑意外重启：登录后双击 `Start FlashRel.bat`，软件会自动从断点继续（中断的那个循环不计数，已记录）。也可以在 Setup 第 ① 步开启 “Enable auto-resume”，登录后自动继续。

## 5. 结束后（120 小时后自动停止，约 1–2 小时）

到点后所有还在跑的盘被记为 censored（删失），状态变成 STOPPED。打开 **Post-test** 页：

1. 每个盘点 “Post-test check”（在原来的口上：读身份文件和哨兵文件、重读最后一个循环留在盘上的文件、再写读删 64 MiB 新数据）。
2. 把 CENSORED 的盘拔掉，空出口。
3. 每个 ATTENTION 的盘：拔下来插到一个空出来的**别的口**，点 “Re-check (other port)”。
4. 把备用盘 A8-09 插到这个坏盘原来的口，点 “Port check with A8-09”。
   - 备用盘在这个口也失败 → 点坏盘那一行的 “Port fault”（是口的问题，不算盘坏）；
   - 备用盘通过、坏盘在别的口也失败 → 点 “Retire: failed”；
   - 备用盘通过、坏盘在别的口又能用了 → 点 “Works again”。
5. 所有坏盘处理完后，到 **Data & control** 页点 “Export ZIP”，然后回 Post-test 页点 “Finish the test”。
6. 把 `exports\` 里的 ZIP（或整个 `data\` 文件夹）发回来做分析。
7. 需要时在 Setup 页点 “Undo host changes” 还原电脑设置。

**不要格式化或修复坏掉的盘**：盘上的损坏就是失效分析的证据。

## 6. 常见问题

| 现象 | 处理 |
| --- | --- |
| 双击 bat 后提示 “Administrator rights were refused” | 软件仍可运行，但不能自动格式化和重启 USB 设备；最好用管理员账户重新运行 |
| 浏览器没有自动打开 | 看黑色窗口里的地址，手动在浏览器打开 |
| 窗口提示 “did not report back” | 窗口里显示了 `data\controller.log` 最后几行，拍照发回来 |
| 某个盘卡片闪橙色边框（missing） | 软件找不到这个盘；先别动，软件会等 2 分钟并自动处理。如果一个坞上 3 个以上的盘在 30 秒内一起消失，会当作拓展坞故障（不计入），等坞恢复后自动继续；坞上别的盘都回来了、这个盘 2 分钟后还没回来，才算这个盘自己的失效 |
| 仪表盘打不开又必须停 | 双击 `Stop FlashRel.bat`；之后可以再用 Start 继续 |
| 插到第十几个盘时 Windows 弹出“没有足够的 USB 控制器资源 / Not enough USB controller resources”，或某个盘插上没反应 | 一个 USB 控制器能管的“端点”数有上限（Intel 常见 96 个；每个 U 盘约 3 个，每个 10 口坞约 12 个）。把拓展坞 B 换到电脑上属于**另一个 USB 控制器**的口（设备管理器 → 查看 → “按连接列出设备”，看两个坞是否挂在不同的 “USB eXtensible Host Controller” 下）；还不行就加一块 PCIe USB 3.0 扩展卡（自带控制器）专门接一个坞 |
| 盘符不够（超过 20 个盘时 Windows 可能分配完 D–Z） | 不影响测试，软件不靠盘符找盘（靠盘里的身份文件和 USB 序列号，读写都走卷的 GUID 路径） |
| 杀毒软件拦截了 PowerShell 或 pnputil | 测试照常进行，只是 USB 位置/自动格式化/自动重启设备不可用；把 `C:\FlashRel-Rig` 加入杀毒软件的信任列表 |
| 某个盘卡死不响应 | 软件 10 分钟没进度会判为 F3 hang 并自动做恢复流程（在恢复流程里又卡住就转为 ATTENTION）；其他 19 个盘不受影响。到了停止时间还卡着的盘，软件最多再等约 11 分钟就结束它，然后照常完成停止和删失 |

## 7. 数据都在哪里

`data\fall2026b\`：

- `drives\<编号>\cycles.csv` 每个循环一行（时间、吞吐量、每文件延迟分位数、错误、累计写入量等）
- `drives\<编号>\events.jsonl` 失效、恢复、退化、备注
- `drives\<编号>\sentinel.csv` 每次“静态数据 + 文件系统记录”检查的结果
- `drives\<编号>\trace.csv` 每分钟的进度（看一个长阶段内速度怎么变化）
- `host\hub_load.csv`、`host\temperature.csv`、`host\host_events.jsonl`、`host\operator.jsonl`
- `life_table.csv`、`fall2026b_workbook.xlsx`（停止时自动生成，Excel 按组/容量/文件大小排好）
